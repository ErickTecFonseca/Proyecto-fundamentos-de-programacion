# Priorización de problemas en una colonia.
# Contexto
En México se es bien sabido que muchas veces no se hace buen uso del recurso publico y este no llega a zonas donde son muchas veces de mayor prioridad, los distintos problemas que afectan a una colonia y sus habitantes muchas veces no son bien cuantificados y en esto converge el proyecto. El saber que zonas deben de tener mayor prioridad en atención de problemas es un factor fundamental para el bien común. Este problema contribuye a distintos factores negativos como lo son la desigualdad social, inseguridad, división social, devaluación de vivienda, el no acceso a servicios básicos y la lista podría seguir ( https://mexico.unir.net/noticias/ciencias-sociales/desigualdad-social/ ).
# Objetico del proyecto.
El objetivo de mi proyecto es el hacer que esto sea mas cuantificable con números y datos y así llegar a un entendimiento superior de los problemas que se viven día a día en la repartición de recursos de las distintas colonias en México y así tener una solución mas eficiente de estos.
